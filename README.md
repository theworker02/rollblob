# rollblob

Roll digests and blob fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/rollblob/

## Install / run

```bash
git clone https://github.com/theworker02/rollblob.git
cd rollblob
node src/cli.js
node --test
```
